# Autoencoder from Scratch with PyTorch

A simple implementation of an **Autoencoder Neural Network using PyTorch** trained on the **MNIST handwritten digit dataset**.

The project demonstrates how an autoencoder can learn a compressed representation of image data and reconstruct the original images from a low-dimensional latent space.

The default model compresses each **28 × 28 MNIST image (784 features)** into a **3-dimensional latent representation** and then reconstructs the original image.

## Overview

An autoencoder is an unsupervised neural network consisting of two main components:

**Encoder:** Compresses the input into a lower-dimensional latent representation.

**Decoder:** Reconstructs the original input from that compressed representation.

For this project:

```text
MNIST Image
28 × 28 pixels
      │
      ▼
Flatten Image
784 features
      │
      ▼
Encoder
784 → 256 → 3
      │
      ▼
Latent Representation
3 dimensions
      │
      ▼
Decoder
3 → 256 → 784
      │
      ▼
Reconstructed Image
28 × 28 pixels
```

## Model Architecture

The autoencoder is implemented using fully connected neural network layers.

| Component | Layer | Output Dimension | Activation |
|---|---|---:|---|
| Input | Flattened MNIST image | 784 | — |
| Encoder | Linear | 256 | ReLU |
| Encoder | Linear | 3 | — |
| Decoder | Linear | 256 | ReLU |
| Decoder | Linear | 784 | Sigmoid |

The **3-dimensional bottleneck** forces the network to learn a compact representation containing the most important information required to reconstruct each digit.

## Dataset

The project uses the **MNIST dataset** available through `torchvision`.

Each image:

```text
Image size: 28 × 28
Flattened size: 784
Pixel values: 0–1
```

Images are converted into PyTorch tensors using:

```python
transforms.ToTensor()
```

The model is trained using batches of **128 images**.

## Training

The autoencoder is trained by minimizing the difference between the original image and reconstructed image.

### Loss Function

```python
nn.MSELoss()
```

Mean Squared Error measures the reconstruction error between the original image and the output produced by the decoder.

### Optimizer

```python
optim.Adam(model.parameters(), lr=1e-3)
```

### Training Configuration

| Parameter | Value |
|---|---:|
| Epochs | 20 |
| Batch Size | 128 |
| Learning Rate | 0.001 |
| Optimizer | Adam |
| Loss Function | Mean Squared Error |
| Default Latent Dimension | 3 |
| Hidden Dimension | 256 |

## Training Results

The reconstruction loss decreases steadily during training.

```text
Epoch 1  Loss: 0.054544
Epoch 5  Loss: 0.038655
Epoch 10 Loss: 0.036470
Epoch 15 Loss: 0.035363
Epoch 20 Loss: 0.034664
```

The reduction in reconstruction loss shows that the autoencoder progressively learns to preserve useful information while compressing MNIST images into a much smaller latent representation.

## Image Reconstruction

After training, the notebook compares the original MNIST images with their reconstructed versions.

```text
Original Images
      ↓
Encoder
      ↓
3D Latent Space
      ↓
Decoder
      ↓
Reconstructed Images
```

The visualization makes it possible to inspect how much visual information the model retains despite reducing each image from **784 dimensions to only 3 dimensions**.

## Latent Space Visualization

The notebook also extracts the representations generated by the encoder and visualizes them based on their MNIST digit labels.

The visualization automatically adapts according to the selected latent dimension:

| Latent Dimension | Visualization |
|---:|---|
| 1 | Histogram and strip plot |
| 2 | 2D scatter plot |
| 3 | 3D scatter plot |
| > 3 | PCA projection into 2D |

With the default configuration, the learned representations are displayed as a **3D latent-space scatter plot**, with points colored according to their digit class.

This helps visualize whether the autoencoder naturally learns meaningful structure among different handwritten digits even though digit labels are not used during training.
